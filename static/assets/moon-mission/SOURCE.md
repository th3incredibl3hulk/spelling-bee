# Moon Mission pixel scenes

Local 4:3 pixel-art style PNGs used by story mode (`data/stories.json` → `image_path`).

Scenes: preflight, countdown, liftoff, orbit, coast, approach, touchdown,
explore, samples, ascent, leave-orbit, reentry, splashdown, recovery, home,
plus `ending-completed.png` and `ending-failed.png`.

Rendered with `image-rendering: pixelated` in the Moon Mission UI.
